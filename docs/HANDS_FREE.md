

## Hands-free desktop tasks

Enable **Hands-free: no approval prompts** in provider settings to run routine desktop actions (including Enter and ordinary Open/confirmation clicks) without approval dialogs. This overrides per-step approval for standalone desktop tasks. A fresh screenshot and separate whole-task visual check replace final human confirmation. The report never labels this as human confirmation.

If a result remains uncertain after the bounded read-only recheck, focus is unclear, clarification is needed, or existing action policy requires review, execution stops with an explanation and no approval prompt. This setting does not expand the supported input operations or bypass mission effect-journal reviews. Disable it to use the existing supervised reviews.
